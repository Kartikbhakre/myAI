# 🤖 AI Chatbot Frontend

A responsive AI chatbot frontend built with React.js and Tailwind CSS. It communicates with the backend API to generate AI-powered responses using the Gemini API.

## 🚀 Features

- Responsive User Interface
- AI-powered Chat
- Text-to-Speech Support
- REST API Integration
- Clean UI

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Axios

## 📦 Installation

```bash
git clone https://github.com/Kartikbhakre/your-frontend-repo.git

cd your-frontend-repo

npm install

npm start
```
